# 1% Mejor

Un espacio semanal para el equipo: una idea de soft skills y una noticia tech, cada semana.

## Cómo actualizarlo cada semana

1. Abre `index.html` y busca el bloque `SEMANAS` al inicio del `<script>`.
2. Copia la semana más reciente y pégala **al inicio** de la lista.
3. Cambia el número de semana, las fechas, los tips, el reto y la noticia tech.
4. Haz commit. GitHub Pages publica los cambios en uno o dos minutos.
