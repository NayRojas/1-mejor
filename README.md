# 1% Mejor

Un tema para crecer, cada semana, en 2 minutos: claves prácticas, una frase lista para usar, un reto, un repaso y una noticia tech.

Página: https://nayrojas.github.io/1-mejor/

## Cómo actualizarlo cada semana

1. Abre `index.html` y busca el bloque `SEMANAS` dentro del `<script>`.
2. Copia la semana más reciente y pégala **al inicio** de la lista.
3. Cambia estos campos:
   - `numero` y `fechas`
   - `soft`: `categoria`, `titulo` (el tema), `ayuda` (en qué ayuda, en una frase), `tips` (máximo 5), `frase` (usa `[corchetes]` para lo que se completa), `fuente` y `reto`
   - `repaso` (opcional): una pregunta sobre la semana anterior, con sus `opciones`, la `correcta` (0 = la primera) y una `explica`
   - `tech`: `etiqueta`, `titulo`, `resumen`, `porQue` (por qué nos importa) y `link`
4. Haz commit. GitHub Pages publica los cambios en uno o dos minutos.

La imagen `og.png` es la que aparece al compartir el link en Teams, WhatsApp u Outlook.
